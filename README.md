# mos-via-6522

The MOS 6522 Versatile Interface Adapter.

| Crate | Registry |
|---|---|
| [`emu198x-mos-via-6522`](crates/emu198x-mos-via-6522) | [crates.io](https://crates.io/crates/emu198x-mos-via-6522) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Commodore PET, VIC-20 and 1541/1571 drives, the Acorn Atom and BBC Micro, and the Oric Atmos.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
